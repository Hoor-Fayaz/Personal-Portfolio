The site highlights:

## Getting Started

### Prerequisites

- Node.js 20+
- npm or yarn

### Installation

```bash
npm install
npm run dev
```

Then open:

```bash
http://localhost:3000
```

### Production Build

```bash
npm run build
npm start
```

### Linting

```bash
npm run lint
```

---

## Deployment

This project is ready for deployment on Vercel.

### Vercel

1. Push the repository to GitHub
2. Import it into Vercel
3. Deploy with the default Next.js settings
